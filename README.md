# Sania Zarnain — Portfolio

A responsive, editorial-style single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Keep `index.html`, `style.css`, `script.js` and the `img/` folder together.
2. Put Sania's original image files in `img/` using the filenames below.
3. Open `index.html` in a browser. For best results, use VS Code Live Server.

## Existing image filenames used
- `img/herosection.png` — hero image/banner
- `img/photo.png` — portrait in About section
- `img/figma.png` — Figma icon
- `img/canva.png` — Canva icon
- `img/udemy.png` — Udemy certificate

The HTML also retains the existing image references from your supplied portfolio where applicable. If an image is missing, the hero and portrait sections show a designed fallback instead of a broken-image icon.

## Before publishing
- Replace the three CSS-built project preview placeholders in the Selected Work section with real project screenshots and links.
- Verify education dates, CGPA, internship dates, contact details and certificate.
- Add a PDF resume link if you want a downloadable resume button.
- Compress large images (WebP recommended) before deployment.

## Deploy
Upload the complete folder to GitHub Pages, Netlify, Vercel static hosting, or any standard web host. No build step or npm installation is required.
